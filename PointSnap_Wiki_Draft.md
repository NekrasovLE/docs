### [Раздел 1] 01_quick_start.md
# Быстрый старт за 60 секунд

Плагин спроектирован по принципу **Zero-Code**: для работы базовой механики не требуется писать C++ код или сложные Blueprints.

## Шаг 1. Настройка детали
1. Откройте любой Blueprint вашего физического предмета.
2. Нажмите **`Add Component`** -> добавьте **`USnapControllerComponent`**.
3. Нажмите **`Add Component`** -> добавьте **`USnapSocketComponent`** и прикрепите его к вашему Mesh Component.

## Шаг 2. Размещение сокета
1. Во вьюпорте Blueprint переместите сокет в точку стыковки.
2. Поверните его так, чтобы стрелка **`EditorArrow`** указывала наружу детали (в направлении стыковки).

## Шаг 3. Задайте роли
- На базовом объекте (верстак, стена, корпус): поставьте `SocketRole = Receiver`.
- На прикрепляемой детали (прицел, крыло, насадка): поставьте `SocketRole = Plug`.
- Для универсальных стыков (труба-к-трубе): оставьте `SocketRole = Bidirectional`.

### [Раздел 2] 02_socket_component.md
# USnapSocketComponent

Компонент обозначает физический порт стыковки детали.

## Роли портов (SocketRole)
- **Receiver (Гнездо / Мама):** Принимает другие детали. Сам никогда не проецирует ghost. Идеально для стационарных баз, верстаков и корпусов.
- **Plug (Штекер / Папа):** Вставляется в сокеты. Проецирует предпросмотр. Идеально для навесных модулей, батареек, магазинов.
- **Bidirectional (Универсальный):** Симметричный сокет. Может и принимать, и вставляться (трубопроводы, рельсы, фермы).

## Контроль вращения сокета (RollMode)
Определяет свободу вращения вокруг оси сокета (Forward +X):
- **Fixed:** Строгая ориентация «верх-к-верху». Несимметричные детали (прицелы, крылья, рукояти).
- **Stepped:** Ступенчатый поворот с фиксированным шагом (`RollSnapSteps = 4` для шага 90°, `6` для 60°). Квадратные блоки, балки, модульные контейнеры.
- **Free360:** Свободное вращение под любым углом 360°. Трубы, цилиндрические шланги, круглые заглушки.

> **Совет:** Чтобы деталь вращалась свободно, достаточно поставить `Free360` только на сокете самой детали. Сокет на стене может оставаться `Fixed` — система автоматически выберет наибольшую свободу.

### [Раздел 3] 03_controller_component.md
# USnapControllerComponent

Компонент контроллера управляет поведением детали в руках игрока.

## Режимы предпросмотра (VisualizerMode)
1. **FullAssemblyGhost (По умолчанию):** Если вы держите в руке узел из нескольких скреплённых деталей, проецируется силуэт всех деталей сборки сразу.
2. **SinglePartGhost:** Классический силуэт только одной прикрепляемой детали.
3. **ConnectorCylinder:** Вместо меша детали отображает аккуратный 3D-цилиндр муфты на сокете.
4. **CustomOnly:** Отключает встроенные меши. Вся визуализация управляется через Blueprint-события.
5. **None:** Полное отключение визуализатора.

## Двуручное VR-управление с натяжением (HL: Alyx Style)
- Если взять сборку двумя руками за разные соединенные части, они не разваливаются сразу. Конструкцию можно передавать из руки в руку, крутить и рассматривать.
- Для отсоединения детали руки нужно развести в стороны дальше порога `DetachTensionDistance` (по умолчанию 18 см).

## Поднятие сборки за любую деталь
Когда сборка лежит на столе, игрок может взять её за любую присоединенную деталь. Вся сборка поднимется монолитным физическим телом.

### [Раздел 4] 04_assembly_manager.md
# USnapAssemblyComponent

Компонент превращает набор деталей в готовое логическое устройство.

## Критерии завершения сборки (ValidationMode)
- **AllSocketsOccupied:** Все сокеты конструкции должны быть заняты.
- **RequiredPartTags:** Все Actor Tags из списка (например, `Battery`, `LeftWing`, `Engine`) должны присутствовать.
- **RequiredPartClasses:** В сборке должны присутствовать указанные классы акторов.
- **Combined:** Комбинация всех вышеперечисленных условий.

## События сборки
- `OnAssemblyCompleted(AssemblyRoot, AssembledParts)` — вызывается при полной готовности устройства.
- `OnAssemblyBroken(AssemblyRoot, RemovedPart)` — вызывается при отсоединении любой ключевой детали.

### [Раздел 5] 05_visualizers_and_events.md
# Кастомные визуализаторы и события

| Событие | Аргументы | Назначение |
| :--- | :--- | :--- |
| `OnSnapCandidateApproached` | `HeldSocket, TargetSocket` | Сокет вошел в зону обнаружения |
| `OnSnapCandidateDeparted` | `HeldSocket, TargetSocket` | Сокет покинул зону обнаружения |
| `OnSnapCandidateProximityChanged` | `Distance, ProximityAlpha, Held, Target` | Непрерывно при сближении (`0.0..1.0`) |
| `OnSnapCandidateAvailabilityChanged` | `bIsAvailable, bCanSnap, Held, Target` | Готовность к защёлкиванию при отпускании |

### [Раздел 6] 06_chaos_physics_and_perf.md
# Физика Chaos и настройки VR

## Изоляция внутренних коллизий (No Glitches)
В Chaos Physics прикрепление твердых тел с пересекающимися коллизиями вызывает силы депенетрации («детали улетают»). PointSnap автоматически изолирует коллизии между всеми деталями внутри сборки через `IgnoreActorWhenMoving`, сохраняя их коллизии с внешним миром.

## Настройки DefaultEngine.ini для 90 FPS в VR:
```ini
r.ForwardShading=True
vr.InstancedStereo=True
r.DynamicGlobalIlluminationMethod=0
r.ReflectionMethod=0
r.Shadow.Virtual.Enable=0
r.RayTracing=False
r.AllowOcclusionQueries=True
```
