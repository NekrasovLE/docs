# PointSnap

PointSnap — плагин для Unreal Engine для физической стыковки деталей по сокетам. Работает по принципу **Zero-Code**: базовая механика настраивается без C++ и сложных Blueprints.

## Возможности

- Роли сокетов: гнездо, штекер, универсальный.
- Контроль вращения вокруг оси стыковки.
- Ghost-предпросмотр сборки и 3D-цилиндры муфт.
- Двуручное VR-управление с натяжением (стиль HL: Alyx).
- Логика сборки: критерии завершения и события.
- Совместимость с физикой Chaos без «улетающих» деталей.
