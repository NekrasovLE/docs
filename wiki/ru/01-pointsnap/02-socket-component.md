# USnapSocketComponent

Компонент обозначает физический порт стыковки детали.

## Роли портов (SocketRole)

| Роль | Описание | Когда использовать |
| :--- | :--- | :--- |
| **Receiver** (Гнездо) | Принимает другие детали. Сам никогда не проецирует ghost. | Стационарные базы, верстаки, корпуса |
| **Plug** (Штекер) | Вставляется в сокеты. Проецирует предпросмотр. | Навесные модули, батарейки, магазины |
| **Bidirectional** | Симметричный сокет: и принимает, и вставляется. | Трубопроводы, рельсы, фермы |

## Контроль вращения (RollMode)

Определяет свободу вращения вокруг оси сокета (Forward, +X):

- **Fixed** — строгая ориентация «верх-к-верху». Несимметричные детали (прицелы, крылья, рукояти).
- **Stepped** — ступенчатый поворот (`RollSnapSteps = 4` → шаг 90°, `6` → 60°). Квадратные блоки, балки, контейнеры.
- **Free360** — свободное вращение на 360°. Трубы, шланги, круглые заглушки.

> [!TIP]
> Чтобы деталь вращалась свободно, достаточно поставить `Free360` только на сокете самой детали. Сокет на стене может оставаться `Fixed` — система автоматически выберет наибольшую свободу.
