# Быстрый старт за 60 секунд

Плагин спроектирован по принципу **Zero-Code**: для базовой механики не нужно писать C++ код или сложные Blueprints.

## Шаг 1. Настройка детали

1. Откройте любой Blueprint вашего физического предмета.
2. Нажмите **`Add Component`** → добавьте **`USnapControllerComponent`**.
3. Нажмите **`Add Component`** → добавьте **`USnapSocketComponent`** и прикрепите его к вашему Mesh Component.

## Шаг 2. Размещение сокета

1. Во вьюпорте Blueprint переместите сокет в точку стыковки.
2. Поверните его так, чтобы стрелка **`EditorArrow`** указывала наружу детали (в направлении стыковки).

> [!TIP]
> Сюда можно добавить скриншот: `![Расположение сокета](./img/socket-placement.png)`.

## Шаг 3. Задайте роли

- На базовом объекте (верстак, стена, корпус): `SocketRole = Receiver`.
- На прикрепляемой детали (прицел, крыло, насадка): `SocketRole = Plug`.
- Для универсальных стыков (труба-к-трубе): оставьте `SocketRole = Bidirectional`.

Подробнее о ролях — в разделе [USnapSocketComponent](./02-socket-component.md).
