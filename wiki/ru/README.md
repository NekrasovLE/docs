## О плагине

**PointSnap** — это высокопроизводительный плагин для Unreal Engine, предназначенный для физической стыковки и модульной сборки деталей по сокетам. Идеально подходит как для стандартных десктопных игр, так и для требовательных **VR-проектов**.

Плагин спроектирован по принципу **Zero-Code**: для настройки базовой механики стыковки не требуется писать код на C++ или создавать громоздкие Blueprints.

### Ключевые возможности:

- 🔌 **Гибкая система сокетов (`USnapSocketComponent`):** поддержка ролей (Receiver, Plug, Bidirectional) и режимов вращения (Fixed, Stepped, Free360).
- 🕹️ **VR-хэндлинг в стиле Half-Life: Alyx (`USnapControllerComponent`):** удержание сборки за любую деталь, двуручный хват с натяжением при отсоединении (`DetachTensionDistance`).
- 👻 **Режимы визуализации:** проецирование силуэта всей сборки (`FullAssemblyGhost`), одиночной детали (`SinglePartGhost`), 3D-цилиндры муфт или полностью кастомные Blueprint-эффекты.
- ⚙️ **Менеджер сборок (`USnapAssemblyComponent`):** валидация готовности устройств по тегам деталей, классам или занятым сокетам, генерация событий завершения сборки.
- ⚡ **Изоляция физики Chaos:** автоматическое отключение взаимных коллизий между собранными деталями для предотвращения физических глитчей и «улетания» объектов.
